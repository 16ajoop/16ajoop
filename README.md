## Featured Projects

### [RAG Projects](https://github.com/16ajoop/RAG_Projects)
End-to-end RAG system that analyzes and refines user queries with an LLM, then retrieves context from a ChromaDB vector store using hybrid semantic and keyword (BM25) search, merged with Reciprocal Rank Fusion and orchestrated through LangGraph.
